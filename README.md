# Supplementary Code for the paper:
**The Fragility of the Reverse Facilitation Effect in the Stroop Task: A Dynamic Neurocognitive Model** 

## Introduction

This repository contains the code associated with the paper titled **The Fragility of the Reverse Facilitation Effect in the Stroop Task: A Dynamic Neurocognitive Model"**
under consideration, also submitted to Virtual MathPsych/ICCM 2025 and available on arXiv here <https://arxiv.org/abs/2503.19128>

### Run

- You can run the notebooks (or view them!) for congruent or incongruent conditions [here](https://github.com/ASohraB/PaperRFE/blob/main/tmp20000Last-tangent-cong-con1_5-2-2_5-3-3Ai1_Prj1_1.ipynb) or [here](https://github.com/ASohraB/PaperRFE/blob/main/tmp20000Last-tangent-incong-con1_5-2-2_5-3-3Ai1_Prj1_1.ipynb) respectively.
- or run the file arxiv1.py (smaller trial numbers recommended, i.e., change 20000 to e.g., 2000 or less!)
